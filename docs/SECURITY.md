# Security Policy

## Responsible Disclosure

If you find a security vulnerability in this code, please email the author
directly. Do NOT open a public GitHub issue for security vulnerabilities.

## Intended Use

This software is intended for:
- Educational and research purposes
- Authorized penetration testing in lab environments
- Blue team / defensive security use on systems you own

Unauthorized deployment on systems you do not own or have
explicit written permission to monitor is illegal and strictly prohibited.
